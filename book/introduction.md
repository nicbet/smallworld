# Introduction {.unnumbered}

Welcome to *Modern Game Engine Design: Building a Hybrid Voxel-Mesh Engine in Rust*.

This book serves as a comprehensive guide to understanding the inner workings of the Smallworld engine. The engine is built from the ground up to tackle the complexities of modern game development, focusing on performance, scalability, and safety.

Throughout the following chapters, we will dive deep into various subsystems—from core foundational concepts like the Game-Render Firewall and thread ownership, through rendering and physics, to tooling and user interfaces. Whether you are looking to contribute to the engine, use it for your next project, or simply learn how a modern, data-driven game engine is architected in Rust, this book provides the necessary theoretical background and practical implementation details.
